PassGone 隐私政策

生效日期：2026 年 9 月 6 日  ·  Effective date: September 6, 2026
中文 English
核心承诺：PassGone 完全离线运行，零联网、零账号、零遥测。你的文件与隐私留在你自己的电脑上。

1. 我们收集什么

什么都不收集。PassGone 不包含任何联网代码、账号体系、统计埋点或崩溃上报。 应用不会读取与你所添加文件无关的任何数据。

2. 数据存放在哪里

数据位置说明
应用设置%LOCALAPPDATA%\PassGone\config.json（商店版）/ 程序目录（便携版）界面选项
找回进度与结果%LOCALAPPDATA%\PassGone\cache\cache.json（商店版）/ 程序目录 cache\（便携版）以文件哈希为键的进度记录（最多 100 条，免费版 2 条）
找回结果备份同上目录 found_passwords.txt成功找回的密码追加记录

这些数据只存在于你的电脑，卸载应用或手动删除文件即彻底清除。

3. 文件会离开你的电脑吗

不会。所有计算（哈希、口令校验）均在本机 CPU / GPU 上完成。 可选的 GPU 加速组件（hashcat）同样完全本地运行，由用户自行提供。

4. 微软商店许可

使用微软商店版时，购买与授权状态由微软商店基础设施管理， PassGone 仅读取本机的许可状态用于解锁完整版功能，不传输任何内容。

5. 未成年人

本软件不面向未成年人提供任何服务，也不收集任何年龄信息。

6. 联系我们

如有隐私相关问题，请通过微软商店页面提供的支持渠道联系开发者；也可写信到 passgone@exifmate.com。

7. 关于本网站

本网站为纯静态 HTML 页面：不含统计分析、行为追踪、Cookie 或任何表单， 除字体与图标外不向任何第三方服务器发起请求（页面内的外部链接仅在你主动点击时才会跳转）。 网站不记录、不存储任何访问者信息。

Our core promise: PassGone runs fully offline: no network access, no accounts, no telemetry.

1. What We Collect

Nothing. The app contains no networking code, analytics, or crash reporting, and never reads anything unrelated to the files you add.

2. Where Data Lives

DataLocationNotes
App settings%LOCALAPPDATA%\PassGone\config.json (Store build) / app folder (portable)UI options
Recovery progress & results%LOCALAPPDATA%\PassGone\cache\cache.json (Store build) / app-folder cache\ (portable)Progress keyed by file hash (up to 100 records; 2 in the Free edition)
Recovered-password backupfound_passwords.txt in the same folderAppend-only record of recovered passwords

This data exists only on your computer; uninstalling the app or deleting the files erases it completely.

3. Do Files Ever Leave Your Computer

No. All computation (hashing, password verification) happens on your local CPU / GPU. The optional GPU acceleration component (hashcat) also runs entirely locally and is user-supplied.

4. Microsoft Store Licensing

In the Microsoft Store build, purchases and license state are managed by Microsoft Store infrastructure; PassGone only reads the local license state to unlock the Full edition and transmits nothing.

5. Minors

This software offers no services directed at minors and collects no age information.

6. Contact

For privacy questions, reach the developer via the support channel on the Microsoft Store listing, or write to passgone@exifmate.com.

7. About This Website

This website is a set of purely static HTML pages: no analytics, no behavioral tracking, no cookies, no forms, and no third-party requests beyond self-hosted fonts and icons (external links open only when you click them). The site records and stores nothing about its visitors.
